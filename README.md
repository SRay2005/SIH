# Smart Scan Strategy

An online scheduler for the SIH26055 Smart Scan Strategy problem. The scheduler chooses a contiguous receiver window from partial observations, tracks emitter activity, and predicts future interceptions.

## Run the benchmark

Requires Python 3.10 or later. The evaluator uses only the Python standard library.

```powershell
python evaluate_submissions.py
```

By default, this evaluates Python submissions in `submissions/` across 47 deterministic scenarios and includes a round-robin baseline. Results are written to `evaluation_output/`.

To evaluate only the current scheduler without the baseline:

```powershell
python evaluate_submissions.py --script scheduler_smartscan.py --no-baseline
```

## Files

- `submissions/scheduler_smartscan.py`: current scheduler implementation.

- `step185.py` and `v6_backup.py`: earlier scheduler experiments.
- `evaluation_output/evaluation_aggregate.csv`: aggregate benchmark metrics.
